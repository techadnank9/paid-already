Build "Paid Already", a single-page web app for creators. Tagline: "You already promote brands for free. Get paid for it." Built for the Hack the Feed hackathon (Oriane video data + GMI Cloud AI + Lovable). DESIGN: dark, premium, editorial. Background #0b0b0c, cards #141412, borders #24231f, text #f2f0ea, muted #8d8a82, single accent lime #c8f169 (the money color). Font Inter or Geist. Big confident headline type, generous spacing, no gradients, no stock illustrations, subtle press scale on buttons, mobile friendly. BACKEND ALREADY EXISTS: do NOT build a backend or database. Put the base URL in one constant API_BASE = "https://paid-already.onrender.com". (1) GET {API_BASE}/api/scan?handle=HANDLE can take up to 2 minutes, show a progress state. It returns JSON { creator: { handle, name, avatar, followers, platform, videosScanned, videosIndexed }, totals: { brands, freeMentions, value, shadowShare, cpm }, brands: [ { name, category, website, freeCount, sponsoredCount, freeViews, shadowCount, value, demand: { sponsoredPosts, sampleCreators: string[] } or null, appearances: [ { signals: array of "said" | "on_screen" | "shown" | "tagged" | "caption", evidence, sponsored, shadow, views, timestamp (seconds or null), frameUrl, thumbnail, postUrl, publishedAt } ] } ] }. On failure it returns { error } with a non-200 status: show it in a red notice. (2) POST {API_BASE}/api/pitch with JSON body { creator: { handle, name, followers, platform }, brand: { name, unpaidMentions: freeCount, unpaidViews: freeViews, estimatedValueUsd: value, moments: first 3 appearances mapped to { quote: evidence, how: signals, views }, alreadyPaysCreators: demand } } returns { subject, body }.
